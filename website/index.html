从下载，到第一条查询

几步，开始读懂你的数据。

不需要终端，不需要安装开发工具。

  1. 01

    下载 Bamboo

    点击免费下载 macOS 版，获取 .dmg 安装文件。M1、M2、M3、M4 等 Apple 芯片 Mac 均属于 Apple Silicon；目前不提供 Intel 版。

  2. 02

    拖入「应用程序」

    双击下载的 DMG，把 Bamboo 拖到 Applications（应用程序）。复制完成后，推出安装磁盘，从「应用程序」打开 Bamboo。

  3. 03

    打开文件，写下 SQL

    将 .parquet 文件拖进欢迎页的大框，或点击 Open data（打开数据）。也可以选择文件夹，或连接 S3 / R2 工作区。

第一次打开被 macOS 拦住？看这里。

当前版本尚未经过 Apple 公证，首次打开时可能提示“无法验证开发者”或“Apple 无法检查其是否包含恶意软件”。确认你从本页链接的 GitHub Release 下载后，可以按以下步骤允许打开。

  1. 先从「应用程序」打开一次 Bamboo；若出现验证提示，关闭该提示。
  2. 打开 系统设置 → 隐私与安全性，向下滚动到“安全性”（旧版系统可能在“安全性与隐私 → 通用”）。
  3. 找到关于 Bamboo 的提示，点击 仍要打开（Open Anyway）。
  4. 按系统要求验证身份，再在确认窗口点击 打开（Open）。

如果没有出现“仍要打开”，先确认刚刚尝试过打开 Bamboo；受单位管理的 Mac 可能需要管理员协助。若系统提示“会损坏电脑”或文件已损坏，请停止打开，重新从 Release 下载，仍有问题可到 GitHub Issues 反馈。查看 Apple 官方说明 ↗

你可能还想知道

常见问题，有问有答

支持哪些 Mac 和文件格式？

目前支持搭载 Apple Silicon 的 Mac（macOS 12 及以上），主要用于读取和查询 Parquet 文件。结果可导出为 CSV 或 JSON。可在  → 关于本机查看芯片与系统版本，目前没有 Intel、Windows 或 Linux 安装包。

文件需要上传吗？云端凭据放在哪里？

Bamboo 没有后端服务器，不会接收或存储你的文件、SQL、查询结果或云端凭据。所有查询和数据处理都在你的 Mac 本地完成，应用配置也保存在本机。连接 S3 或 R2 时，由你的 Mac 直接按需读取你自己的云端存储；访问凭据仅保存在本机的 macOS 钥匙串中。

打开文件后，第一条 SQL 怎么写？

对当前文件，输入 SELECT * FROM data LIMIT 100;，点击 Run query（运行查询）即可。文件夹工作区支持跨文件查询，例如 SELECT * FROM workspace."orders.parquet" LIMIT 100;。你也可以直接预览、筛选和排序，不必先写 SQL。

会修改打开的 Parquet 文件吗？

不会。Bamboo 以只读方式打开和查询 Parquet 文件，预览、筛选、排序和 SQL 查询都不会修改原文件。导出结果会创建新文件。

如何更新 Bamboo？

Bamboo 可以在后台检查更新，有新版本时会在左下角提示。点击更新提示，按提示确认安装并重新启动即可；你也可以在「设置 → 通用」中手动检查更新。安装和重启都需要你主动确认，不会在使用过程中自动升级。更新从本项目的 GitHub Releases 获取。

Bamboo 收费吗？遇到问题在哪里反馈？

Bamboo 免费开源，采用 MIT 许可证。发现 Bug 可以到 GitHub Issues；使用问题、想法和建议欢迎到 GitHub Discussions 讨论。反馈时请注明应用版本、macOS 版本和重现步骤，并隐去密钥、私人路径和业务数据。

官网不包含统计脚本、广告、追踪像素或反馈表单，也不设置追踪 Cookie。浏览器的 localStorage 仅用于保存你选择的语言与浅色或深色主题，不会由页面发送给维护者；你可以通过浏览器清除本站数据来删除这些偏好。

在线访问仍需要网络请求。网站托管商、CDN 或网络服务商可能处理 IP 地址、访问时间、请求网址、浏览器信息等常规请求元数据，用于内容交付、安全和运维；具体处理与留存取决于实际托管服务的配置和政策。这与页面是否加载统计脚本是不同的。

2. 文件、查询与本地保存

本地 Parquet 数据和 SQL 在你的设备上处理，不会上传给 Bamboo 维护者。应用会在本地保存设置、工作区路径、连接配置和 SQL 草稿；这些内容可能包含敏感信息。查询可能使用本地缓存及临时磁盘，导出结果保存在你选择的位置。异常退出后可能遗留临时数据。

关闭工作区或卸载应用不一定清除已保存的配置、凭据、临时文件和导出结果。你可以在设置中删除不需要的云连接，并按需清理本机应用数据、钥匙串和自行导出的文件。删除云连接不会删除云端对象。

3. 云存储连接

只有连接你配置的 Amazon S3 或 Cloudflare R2 时，应用才会向相应服务发送经过身份验证的列举、元数据和文件读取请求。服务商会收到这些请求及必要的网络元数据，处理方式受你的云服务协议约束。文件查询在本机执行。

macOS 版本将云访问凭据保存在系统钥匙串；连接配置和 SQL 草稿保存在本机。凭据不发送给 Bamboo 维护者。请按最小权限配置只读凭据，并在不再需要时删除连接及撤销相应授权。

应用默认启用自动检查更新，可在 Settings → General 中关闭。检查和下载通过 HTTPS 访问 GitHub Releases 及其下载基础设施；服务方会收到 IP 地址及版本检查所需的常规 HTTP 元数据。应用不会在检查中发送文件路径、查询内容、云凭据或 Sparkle 系统概况。安装和重启须由你主动确认。
