Bamboo's first release brings a focused Parquet workbench to macOS.

- **Explore files quickly.** Open a Parquet file or folder, inspect its schema, filter and sort rows, and keep multiple workspaces organized.
- **Ask questions with SQL.** Query a single file or combine files across an opened workspace, then export results as CSV or JSON.
- **Read from cloud storage.** Connect Amazon S3 and Cloudflare R2 buckets or prefixes with read-only access. Credentials stay in macOS Keychain.
- **Work with large datasets.** Bounded range reads, reusable caches, and configurable memory and temporary-disk budgets help keep resource use under control.
- **Make it yours.** Choose English or Chinese, light or dark appearance, or follow the system.
- **Stay up to date.** See new-version reminders in the sidebar or check in Settings. Installation and restart require your confirmation. Update metadata and downloads are verified with Sparkle signatures and delivered through this repository's GitHub Releases.

### Install

Download **Bamboo-0.1.0-macOS-arm64.dmg**, open it, and drag Bamboo into Applications.

Requires an Apple Silicon Mac running macOS 12 or later. This build is ad-hoc signed and is not Apple-notarized; macOS may require you to allow it in System Settings → Privacy & Security after the first launch attempt.

The accompanying SHA-256 file lets you verify the installer download. The signed `appcast.xml` is used by the app's automatic update checker.
