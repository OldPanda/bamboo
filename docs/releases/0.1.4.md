Bamboo 0.1.4 opens wide Parquet files without the previous 256-column preview limit.

- Preview all columns in local files, folder workspaces, Amazon S3 and Cloudflare R2. Wide-file regressions cover up to 4,096 columns.
- Keep previews bounded by reducing rows per page for wide results. For example, a 4,096-column result shows up to 31 rows per page, with a visible explanation and correct next/previous navigation.
- Preserve exact values, NULL and empty text, and support sorting and filtering on later columns. Reading a file does not modify it.
- Retain query resource limits and bound schema metadata. If a schema is too large, select the columns you need in a workspace query.

All three desktop platforms ship together with SHA-256 checksums:

- **macOS Apple Silicon, macOS 12+:** open `Bamboo-0.1.4-macOS-arm64.dmg` and drag Bamboo into Applications. The app is ad-hoc signed, **not Apple-notarized**; after the first launch attempt, macOS may require approval in System Settings → Privacy & Security.
- **Windows 10/11 x64:** use `Bamboo-0.1.4-windows-x64-setup.exe`, or extract `Bamboo-0.1.4-windows-x64.zip`. Requires Microsoft Edge WebView2 Evergreen x64 Runtime. Packages are **unsigned** and may trigger SmartScreen.
- **Ubuntu 22.04+ / compatible Debian x64 desktop:** install `Bamboo-0.1.4-linux-x64.deb`, or extract `Bamboo-0.1.4-linux-x64.tar.gz`. Requires GTK 3, WebKitGTK 4.1, libsecret, libstdc++, glibc 2.35+ and xdg-utils; the portable archive does not install those libraries. Other distributions have not been validated.

Existing workspaces and open files are restored after restart. macOS checks for updates hourly; installation and restart still require your confirmation.
