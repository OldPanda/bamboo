Bamboo 0.1.3 improves Parquet compatibility and preserves empty records in CSV exports.

- Open SAP-style Parquet DECIMAL columns that omit scale, using the format's default of zero while preserving exact values. Invalid decimal metadata is rejected. Precision above 38 digits is explicitly unsupported instead of being approximated as floating point.
- Keep every single-column CSV record, including leading, middle and trailing NULL or empty text. CSV still represents NULL and empty text alike; JSON keeps them distinct. Nanosecond time values retain their precision.
- Restore open workspaces, independent files and the active selection after restart, with a bounded preview and without automatically running previous SQL.
- Check for macOS updates hourly and show a quiet reminder. Installing and restarting still requires an explicit action.

All three desktop platforms ship together with SHA-256 checksums:

- **macOS Apple Silicon, macOS 12+:** open `Bamboo-0.1.3-macOS-arm64.dmg` and drag Bamboo into Applications. The app is ad-hoc signed, **not Apple-notarized**; after the first launch attempt, macOS may require approval in System Settings → Privacy & Security.
- **Windows 10/11 x64:** use `Bamboo-0.1.3-windows-x64-setup.exe`, or extract `Bamboo-0.1.3-windows-x64.zip`. Requires Microsoft Edge WebView2 Evergreen x64 Runtime. Packages are **unsigned** and may trigger SmartScreen.
- **Ubuntu 22.04+ / compatible Debian x64 desktop:** install `Bamboo-0.1.3-linux-x64.deb`, or extract `Bamboo-0.1.3-linux-x64.tar.gz`. Requires GTK 3, WebKitGTK 4.1, libsecret, libstdc++, glibc 2.35+ and xdg-utils; the portable archive does not install those libraries. Other distributions have not been validated.
