Bamboo 0.1.5 fixes keyboard focus when sorting query results and adds English and Chinese getting-started documentation.

- Keep the column header focused while a sort is running and after results refresh. Respect focus moved elsewhere, retain the previous sort direction after a failed query, and expose the sort state to assistive technology.
- Document installation on all three platforms, opening local files and S3/R2 workspaces, and read-only SQL examples at [getbamboo.app/en/docs/](https://getbamboo.app/en/docs/) and [getbamboo.app/zh/docs/](https://getbamboo.app/zh/docs/).
- Expand INT96 compatibility and exact-value regression coverage. Default INT96 reads still use `TIMESTAMP` with **microsecond precision**. The documented, existing `read_parquet(..., int96_as='struct')` option retains nanoseconds for an already-opened, authorized local file; this release does not change the default schema or add a cloud precision setting.

All three desktop platforms ship together with SHA-256 checksums:

- **macOS Apple Silicon, macOS 12+:** open `Bamboo-0.1.5-macOS-arm64.dmg` and drag Bamboo into Applications. The app is ad-hoc signed, **not Apple-notarized**; after the first launch attempt, macOS may require approval in System Settings → Privacy & Security.
- **Windows 10/11 x64:** use `Bamboo-0.1.5-windows-x64-setup.exe`, or extract `Bamboo-0.1.5-windows-x64.zip`. Requires Microsoft Edge WebView2 Evergreen x64 Runtime. Packages are **unsigned** and may trigger SmartScreen.
- **Ubuntu 22.04+ / compatible Debian x64 desktop:** install `Bamboo-0.1.5-linux-x64.deb`, or extract `Bamboo-0.1.5-linux-x64.tar.gz`. Requires GTK 3, WebKitGTK 4.1, libsecret, libstdc++, glibc 2.35+ and xdg-utils; the portable archive does not install those libraries. Other distributions have not been validated.

Existing workspaces and open files are restored after restart. macOS checks for updates hourly; installation and restart still require your confirmation.
