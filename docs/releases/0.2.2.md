Bamboo 0.2.2 adds query history and named saved queries.

- Open the searchable Query history dialog from the right edge of the editor. History records successful manual runs; Saved keeps queries you name for reuse, with rename and delete actions.
- Open a query in its original source's editor without running it. Draft replacement requires confirmation, and queries from another source cannot replace the current editor.
- History and saved queries persist privately on this device across restarts. Clear history retains saved queries. SQL, names and source paths are stored locally without encryption; result rows and connection credentials are not stored.

Update installation and restart still require an explicit user action. Existing data files, settings and saved workspaces remain compatible. See [query history](https://github.com/OldPanda/bamboo/blob/v0.2.2/docs/query-history.md) for storage limits and behavior.

All five packages include SHA-256 checksums: macOS Apple Silicon DMG, Windows x64 setup EXE and portable ZIP, and Linux x64 DEB and tar.gz. macOS is ad-hoc signed, not Apple-notarized; Windows packages are unsigned. See the [installation guide](https://getbamboo.app/en/docs/#installation) for platform requirements.

## 中文

Bamboo 0.2.2 新增查询历史与命名保存查询。

- 编辑器右侧的查询记录按钮打开可搜索弹窗。历史仅记录主动运行且成功的查询；已保存页签保留命名查询，支持重命名与删除。
- 查询仅能打开到原数据源的编辑器，不会自动执行。替换未执行的草稿需要确认，其他数据源的查询无法覆盖当前编辑器。
- 查询历史与已保存查询保存在本机私有配置中，重启后仍可使用。清空历史会保留已保存查询。SQL、名称和数据源路径在本地以未加密形式保存，不保存结果行或连接凭据。

更新安装和重启仍需用户主动确认，现有数据文件、设置和已保存工作区保持兼容。存储限制与操作说明详见[查询记录文档](https://github.com/OldPanda/bamboo/blob/v0.2.2/docs/query-history.md)。

三个桌面平台同时提供五种包和 SHA-256：macOS Apple Silicon DMG、Windows x64 安装 EXE 与 ZIP、Linux x64 DEB 与 tar.gz。macOS 为临时签名且未经 Apple 公证，Windows 未签名。平台依赖详见[安装指南](https://getbamboo.app/zh/docs/#installation)。
