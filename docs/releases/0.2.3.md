Bamboo 0.2.3 improves query cancellation. The previous result stays visible and remains available for export and analysis while Bamboo finishes cleaning up the cancelled query.

This release upgrades MyGo to 0.9.2 and builds with Go 1.27.4 to address GO-2026-6859. Installing an update and restarting still require your confirmation.

The Apple Silicon DMG, Windows x64 setup EXE and ZIP, and Linux x64 DEB and tar.gz each come with a SHA-256 checksum. The macOS app is ad-hoc signed and has no Apple notarization. Windows packages are unsigned.

## 中文

Bamboo 0.2.3 改进了查询取消。清理已取消的查询期间，上一份结果仍然可见，也可以继续导出和分析。

此版本将 MyGo 升级至 0.9.2，并使用 Go 1.27.4 构建以修复 GO-2026-6859。安装更新和重启仍需主动确认。

Apple Silicon DMG、Windows x64 安装 EXE 和 ZIP，以及 Linux x64 DEB 和 tar.gz 均提供 SHA-256 校验文件。macOS 应用采用临时签名，未经 Apple 公证。Windows 安装包未签名。
