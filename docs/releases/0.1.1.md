Bamboo 0.1.1 brings the Parquet workbench to macOS Apple Silicon, Windows x64 and Linux x64.

- Open local files and folders, or explicitly configured Amazon S3 and Cloudflare R2 workspaces.
- Explore schemas and exact values, run read-only SQL, and export selected results as CSV or JSON.
- Choose English or Chinese, light or dark appearance, and adjustable memory and temporary-disk budgets.
- The bilingual website now offers platform-aware downloads and first-install instructions.

### Install

- **macOS Apple Silicon, macOS 12+:** open `Bamboo-0.1.1-macOS-arm64.dmg` and drag Bamboo into Applications. The app is ad-hoc signed, **not Apple-notarized**; after the first launch attempt, macOS may require approval in System Settings → Privacy & Security.
- **Windows 10/11 x64:** use `Bamboo-0.1.1-windows-x64-setup.exe`, or extract `Bamboo-0.1.1-windows-x64.zip`. Requires Microsoft Edge WebView2 Evergreen x64 Runtime. Packages are **unsigned** and may trigger SmartScreen.
- **Ubuntu 22.04+ / compatible Debian x64 desktop:** install `Bamboo-0.1.1-linux-x64.deb` with `sudo apt install ./Bamboo-0.1.1-linux-x64.deb`, or extract `Bamboo-0.1.1-linux-x64.tar.gz`. Requires GTK 3, WebKitGTK 4.1, libsecret, libstdc++, glibc 2.35+ and xdg-utils; the portable archive does not install those libraries. Other distributions have not been validated.

Cloud credentials stay in the platform vault: macOS Keychain, Windows Credential Manager or Linux Secret Service. Linux cloud connections require a user D-Bus session and an unlocked Secret Service such as GNOME Keyring.

Every package has a SHA-256 companion file. The signed `appcast.xml` supplies macOS update checks; installing and restarting require explicit confirmation. Windows/Linux update checks open the releases page for manual installation. No Intel Mac or Windows/Linux ARM64 package is included.
