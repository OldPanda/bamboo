Bamboo 0.2.0 adds complete-result exports, local CSV/TSV input, display controls,
and on-demand analysis while keeping source files read-only.

- **Export the complete query:** choose the current page or complete result in
  CSV, TSV, JSON or JSONL. Complete exports rerun the last successful query with
  its filter, sorting and projection, stream within resource budgets, show row
  progress and support cancellation. Existing files are never overwritten;
  failed exports are not published as complete files. JSON and JSONL retain
  exact strings, types and NULLs. JSONL starts with a metadata record. CSV/TSV
  protect formula-like text and do not distinguish NULL from empty text.
- **Open local CSV and TSV:** open single files or discover them in folders,
  restore sessions and join them with Parquet in the same workspace. Choose a
  delimiter, header interpretation and optional conservative type inference.
  UTF-8 is supported, including a BOM, quoted delimiters and multiline fields.
  Text-preserving defaults retain leading zeros and precise numeric text;
  malformed input fails visibly. S3/R2 input remains Parquet-only.
- **Adjust display size:** General settings provides native application zoom
  from 75% to 200% and data text from 12 to 20 px, with reset and restart
  persistence. SQL text follows the data size with one extra pixel.
- **Analyze the complete query:** explicitly request exact counts, NULLs,
  distinct values, min/max and the 20 most frequent values. Build a grouped
  COUNT/SUM/AVG/MIN/MAX pivot and export its independent snapshot. Profiles
  reject more than 10,000 distinct non-NULL values; pivots reject more than
  1,000 groups or 4 MiB of value text. These are complete results, never samples
  or silent truncation. AVG follows DuckDB's floating-point SQL semantics.

Complete exports and analysis read sources again; they are not transactional
copies of the original preview. Normal preview limits, read-only SQL validation,
workspace scope checks, exact IPC values, query budgets and cancellation remain.

All three desktop platforms ship together with SHA-256 checksums:

- **macOS Apple Silicon, macOS 12+:** open
  `Bamboo-0.2.0-macOS-arm64.dmg` and drag Bamboo into Applications. The app is
  ad-hoc signed, **not Apple-notarized**; first launch may require approval in
  System Settings → Privacy & Security.
- **Windows 10/11 x64:** use `Bamboo-0.2.0-windows-x64-setup.exe` or extract
  `Bamboo-0.2.0-windows-x64.zip`. Requires Microsoft Edge WebView2 Evergreen x64
  Runtime. Packages are **unsigned** and may trigger SmartScreen.
- **Ubuntu 22.04+ / compatible Debian x64 desktop:** install
  `Bamboo-0.2.0-linux-x64.deb` or extract `Bamboo-0.2.0-linux-x64.tar.gz`.
  Requires GTK 3, WebKitGTK 4.1, libsecret, libstdc++, glibc 2.35+ and xdg-utils;
  the portable archive does not install them. Other distributions have not
  been validated.

Existing workspaces and open files are restored after restart. macOS update
checks may announce a version; installation and restart still require your action.

## 中文

Bamboo 0.2.0 新增完整结果导出、本地 CSV/TSV 打开、字号与缩放，以及按需列统计和透视分析。

- 导出可选当前页或完整查询结果，支持 CSV、TSV、JSON、JSONL；完整导出显示进度、
  可取消、不覆盖已有文件，失败时不发布不完整文件。JSON/JSONL 保留精确值和 NULL，
  JSONL 首行为元数据；CSV/TSV 防止文本公式注入，但无法区分 NULL 与空文本。
- 本地文件与文件夹支持 CSV/TSV，保留会话，并可与同工作区的 Parquet 联表查询。
  支持 UTF-8、BOM、引号及多行字段，可调整分隔符、表头和保守类型推断。默认按文本
  读取以保留前导零和精确数字；云端 S3/R2 本轮仍仅支持 Parquet。
- 通用设置可调整 75%–200% 应用缩放、12–20 px 数据字号，支持重置与重启恢复。
- 分析基于完整的最后成功查询，可计算总数、NULL、不同值、最小/最大值与高频值，
  并生成 COUNT/SUM/AVG/MIN/MAX 透视和独立导出。列统计超过 10,000 个不同非 NULL
  值、透视超过 1,000 组或 4 MiB 时明确报错，不采样或静默截断。AVG 遵循 SQL 浮点语义。

完整导出与分析会重新读取源文件，不代表预览时源字节的事务快照。数据只读、路径范围、
资源预算和取消机制继续生效。三个桌面平台同时提供安装包及 SHA-256；macOS 为临时
签名且未经 Apple 公证，Windows 安装包未签名。更新安装与重启仍需用户主动确认。
