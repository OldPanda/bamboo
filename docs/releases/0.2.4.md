Bamboo 0.2.4 updates the Node.js build and CI toolchain to 22.23.5, a security release, and removes two unused connection translations.

The Apple Silicon DMG, Windows x64 setup EXE and ZIP, and Linux x64 DEB and tar.gz each come with a SHA-256 checksum. The macOS app is ad-hoc signed and has no Apple notarization. Windows packages are unsigned.

## 中文

Bamboo 0.2.4 将构建和 CI 使用的 Node.js 工具链更新至安全版本 22.23.5，并移除两条未使用的连接界面译文。

Apple Silicon DMG、Windows x64 安装 EXE 和 ZIP，以及 Linux x64 DEB 和 tar.gz 均提供 SHA-256 校验文件。macOS 应用采用临时签名，未经 Apple 公证。Windows 安装包未签名。
