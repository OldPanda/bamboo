Bamboo 0.2.1 improves repeated workspace queries and wide result tables.

- Local Parquet workspace queries can reuse one validated catalog for up to 30 idle seconds. Each query still checks file identity, read access and workspace boundaries; CSV/TSV options continue to bind afresh.
- S3 and R2 workspace queries can reuse verified object ranges while retaining fresh signed HEAD checks, version checks and new scoped gateways. All readers share bounded cache and transfer budgets.
- Wide result pages reuse table cells and avoid expensive automatic column layout. Every column and exact value remains available for scrolling, text selection, browser find and accessibility.

Retained data is not a transactional snapshot of concurrent changes. Cache budgets are not total application memory limits. Existing source files, settings and saved workspaces remain compatible. Update installation and restart still require an explicit user action.

All five packages include SHA-256 checksums: macOS Apple Silicon DMG, Windows x64 setup EXE and portable ZIP, and Linux x64 DEB and tar.gz. macOS is ad-hoc signed, not Apple-notarized; Windows packages are unsigned. See the [installation guide](https://getbamboo.app/en/docs/#installation) for platform requirements.

## 中文

Bamboo 0.2.1 优化重复工作区查询与宽表结果显示。

- 本地 Parquet 工作区可复用经过验证的目录，空闲 30 秒后释放。每次查询仍检查文件身份、读取权限和工作区范围；CSV/TSV 的读取选项每次重新绑定。
- S3 与 R2 可复用已验证的对象分块，每次仍进行签名 HEAD 和版本检查，并使用新的独立网关。所有读取器共享有界缓存和传输预算。
- 宽表复用单元格并减少自动列宽布局开销，保留全部列、精确值、滚动、文本选择、浏览器查找和辅助功能语义。

缓存不构成并发修改下的事务快照，也不是应用总内存上限。现有文件、设置和已保存工作区保持兼容；更新安装和重启仍需用户主动确认。

三个桌面平台同时提供五种包和 SHA-256：macOS Apple Silicon DMG、Windows x64 安装 EXE 与 ZIP、Linux x64 DEB 与 tar.gz。macOS 为临时签名且未经 Apple 公证，Windows 未签名。平台依赖详见[安装指南](https://getbamboo.app/zh/docs/#installation)。
